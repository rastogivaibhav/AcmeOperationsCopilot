# Security and responsible publication

This repository is a **local-only fictional case-study prototype**. It contains Keycloak *demo credentials* for repeatable offline assessment. They are not real secrets and must never be used on a publicly exposed service. Do not expose ports or deploy this configuration outside localhost.

- Keep actual credentials, private customer records, and token dumps out of commits. `.env` is ignored; `.env.example` has local defaults only.
- CI uses ephemeral services, deliberately fictitious records and repository read-only GitHub Actions permissions. Avoid uploading raw Compose logs as public artifacts because future logs could inadvertently contain business information.
- Do not use this system with real clients without TLS, dedicated production identity credentials, verified service-to-service delegation, production data access policies, secret management, data retention rules, threat modelling and operational hardening.
- Agent runs retain only limited identity-attributed metadata, durations, tool names, symbolic evidence references and error codes. Human business writes are separately attributed in the audit table.
- This work originated from a confidential recruitment assessment. Keep the candidate pack and solution out of public repositories, and share the private source only with reviewers EY has expressly authorised to evaluate it. Confirm permission before any broader publication.
- **Verified on 11 November 2026:** GitHub Actions ran Docker Compose, Keycloak/MCP, browser OIDC, authenticated role boundaries, the model/Skill evaluations and controlled-write smoke tests using disposable fixtures. The [PR full-stack run](https://github.com/rastogivaibhav/AcmeOperationsCopilot/actions/runs/42983299825) passed with a 10/10 structural W13 score; [merged-source CI](https://github.com/rastogivaibhav/AcmeOperationsCopilot/actions/runs/42984994299) also passed. The independent [post-merge integration run](https://github.com/rastogivaibhav/AcmeOperationsCopilot/actions/runs/42984994525) also passed the security and agent-quality gates. This is **not** a penetration test or production security certification.
- Keep this repository **private**, invite only the specifically authorised EY reviewers, and avoid emailing committed demo-password screenshots, live bearer tokens or private run artifacts to broader recipients.
